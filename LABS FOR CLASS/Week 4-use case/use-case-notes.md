## Week 4 Requirements modelling




## Requirements used
- System shall control bookings return date
- System shall be usable for staff
- System shall work all around the facility
- System shall track available equipment


## Actors
- Professors
- Administration
- Mechanics



## Use Cases
- Equipment Availability
- Create Booking
- Record Return Equipment
- Work Around Facilities


## Unknowns / Questions
- When a user tries to create a booking, does it check for equipment availability
- What does work around facilities actually mean?


## Reflection
One thing the diagram has helped me is to realise that everything is more linked than it seems. Despite having diffirent actors or diffirent requirements, a lot of them crossover.

One requirement question that really shocked me was the work all around facilities. It made sense to me because of course you want the system to work through the entire college but I didn't specify it, so what did that truly mean.
